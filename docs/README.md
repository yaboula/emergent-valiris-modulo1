# Documentation

Documentation is treated as code: every document is versioned, reviewed through pull requests and kept up to date with the product.

| Area | Location | Produced in |
| --- | --- | --- |
| Project charter: purpose, quality bar, principles, standards, roles, risks | [`project/charter.md`](project/charter.md) | M0.1 |
| Roadmap and milestones | [`project/roadmap.md`](project/roadmap.md) | M0.1 |
| Glossary (ubiquitous language, EN/ES) | [`glossary.md`](glossary.md) | M0.1, then continuously |
| Architecture decision records | [`adr/`](adr/README.md) | Continuously |
| Research: market, competitors, interviews, legal | `research/` | M0.2 |
| Product: vision, personas, story map, scope | `product/` | M0.3 |
| Software requirements specification | `srs.md` | M0.3 |
| Architecture: C4, data model, events, threat model | `architecture/` | M0.4 |
| Design: art direction, design system, flows | `design/` | M0.5 |
| Testing: strategy, manual test plans, reports | `testing/` | M0.4, then per milestone |
