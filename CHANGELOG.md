# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- M0 executive execution brief: closure evidence, priorities, responsibility boundaries, coordinated commercial/service work, resource gaps, decisive risks and an actionable Product handoff.
- Repository bootstrap: README, proprietary license, editor and git settings, contribution guide, issue and pull request templates.
- M0.1 kick-off documentation: project charter, roadmap, glossary (EN/ES), documentation index.
- ADR-0001 to ADR-0005: ADR process, studio brand (accepted risk), product name, repository visibility and license, repository and product language.
- M0.2 discovery research: Spanish market and digitalisation evidence, competitor feature/pricing comparison, 50 traceable public reviews, interview guide and three labelled fictional scenarios, legal constraints, source and verification registers, and Gate 1 recommendation pending review.
- Proposed ADR-0006: distinguish portfolio discovery from commercial demand validation.
- Seven module-specific discovery inputs and an English advanced-research framework with a linked reference list.
- Storefront + Digital Menu master research in Spanish and English: 59 products across Spain, Europe and North America, with complete inventories, capability matrices and source links.
- Original Spanish Storefront + Digital Menu functional-definition proposal and its interactive HTML presentation.

### Changed

- Clarify applicable versus unknown dish allergens, mark unsupported historical brand findings as unverified leads, and distinguish documentation outcomes from software releases. Allow owner-delegated review and squash merge while retaining branch protections.
- Replace the seven-module/17-week plan with a first-product M0–M7 roadmap; v1.0 is Storefront + Digital Menu with necessary Core and delivery service. Align charter, contribution rules, documentation, vocabulary and tracker; preserve historical research with applicability notes.
- Record ADR-0007, retire the former discovery-gate proposal, and move real pilot evidence and commercial launch to M6/M7.

- Clarify consent, visit confirmation, no-show measurement and payment terminology in the glossary following discovery research.
- Describe the planned product and its unvalidated outcomes explicitly in the repository introduction.
